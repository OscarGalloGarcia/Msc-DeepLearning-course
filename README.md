# Msc-DeepLearning-course
Deep Learning coursework, implementations, and experiments developed as part of my Master's degree in Artificial Intelligence.


This repository contains my completed exercises, implementations, and study notes developed as part of the Deep Learning course in the Master's Degree in Robotics and Artificial Intelligence at the Universidad de Guadalajara.

The course is taught by PhD Carlos Villaseñor, who is the original author of the instructional material and Jupyter notebooks on which this repository is based.

About this repository

The original course repository provides a collection of Jupyter notebooks designed as guided Deep Learning lessons and exercises.

As part of my study of the subject, I worked through these lessons and completed the sections, implementations, exercises, and experiments that were intentionally left unfinished for students.

This repository therefore represents my personal study and coursework based on those materials.

My main goals with this repository are to:

Reinforce the theoretical concepts covered during the course.
Implement Deep Learning concepts from scratch when appropriate.
Complete the exercises proposed in the original lessons.
Experiment with the models and algorithms presented in class.
Keep a structured record of my learning process throughout the course.
